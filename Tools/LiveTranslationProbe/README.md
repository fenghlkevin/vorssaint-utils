# 系统声音实时字幕：独立验证程序

不属于主应用构建；不修改或替换已安装的 Vorssaint。需要 Apple Silicon、macOS 26 和相应 SDK。

## 构建、运行

```sh
bash Tools/LiveTranslationProbe/build.sh
open 'build/Live Translation Probe.app'
```

默认使用当前开发证书，可通过 `VORSSAINT_DEV_SIGNING_IDENTITY` 覆盖。

## 验证方式

1. 点击「开始 5 分钟验证」。首次使用需要在系统设置的「隐私与安全性 → 屏幕与系统音频录制」允许 Live Translation Probe；授权后可能需要退出并重开。
2. 播放英文视频/直播，关闭其他有声应用。首版捕获整个系统，不支持指定应用。
3. 确认帧计数增加、音量随播放变化、英文临时字幕和确定段落出现。
4. 已安装英→中 Apple 翻译包时，确定段落串行翻译；否则仅识别，不自动下载、不走云端备用服务。
5. 对照视频字幕人工核对漏词、断句、译文和声音的滞后。首条识别时间包含开始后等待播放的时间，不能当作纯模型延迟；每段翻译耗时也不等于端到端延迟。
6. 观察 5 分钟后自动停止，或手动停止。退出清空内存字幕。

## 实现和限制

- 延迟指标使用单调时钟：首个有效 PCM 音频包到达、首次有声抽样（−50 dB，约 250ms 间隔）、首条有效英文回调、SwiftUI 视图更新，以及最近一次英文回调到视图更新。
- 首包到英文包含静音；首次有声可能是音乐而不是人声；视图更新不等于实际屏幕呈现。指标用于定位等待阶段，不能当作精确的语音端到端延迟。
- 每次开始采集重置指标，停止后保留；固定英文自检清空且不填充音频延迟指标。

- 低延迟预览：英文稳定 1 秒后提前提交；连续变化时每约 2 秒提交一次（至少 5 词）。长段按标点或 18 词分块。
- 按识别音频段起点更新同一组字幕，定稿后修正；原文不变不重复翻译，过时结果不覆盖新原文。
- 每次翻译使用独立、不可变的任务标识及视图生命周期；完成、错误、取消均释放当前队列，12 秒超时也会释放。旧任务不能修改新任务状态。
- 定稿音频范围会清除过期预译并屏蔽迟到的同范围识别结果，避免定稿后重复追加。
- 「固定英文自检」不采集音频：模拟时间戳修正、定稿后迟到预览和后续句子，预期仅留下两条已定稿中文译文，不应永久显示“等待翻译”。
- “本段首条英文→提交”是从该识别段首条英文出现到此次更新提交的时间，后续修正会增大，不是音频端到端延迟。“翻译执行”不含排队。

- ScreenCaptureKit 只注册 `.audio` 输出；麦克风关闭、当前进程音频排除，无 `.screen` 输出，无录音写盘。
- Apple SpeechTranscriber / SpeechAnalyzer 流式本地识别，使用已有英语模型。
- 不读取 AI API 配置、Keychain 或主应用偏好，不调用收费 API。
- 音频输入有界队列溢出时停止并提示；字幕最多 80 段，译文队列过长时跳过旧句。
- 停止时立即取消识别，未定稿尾句会丢弃；这不是正式版字幕同步实现。
- 暂未实现音画同步、指定应用、悬浮字幕、断点跳转检测或准确率自动评测。

## 2026-09-17 验证记录

- 主机 macOS 26.5 / arm64；编译、现有 Apple Development 证书签名验证通过。
- 系统服务只读查询确认英语等本地语音模型已安装；应用界面确认英语模型就绪。
- 应用启动成功；Apple LanguageAvailability 报告英→中语言包未安装，未触发下载。
- 启动捕获被 TCC 权限拒绝，因此尚未实际验证音频、识别、译文、5 分钟稳定性或负载，不能宣称实时翻译链路已通过。
- 下一步需要用户授予此独立程序采集权限并播放英文素材；双语测试另需安装系统翻译语言包。

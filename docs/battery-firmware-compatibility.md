# 未适配固件的降级行为

后台可连接且签名/版本验证通过，不代表充电控制可用。接口缺失或格式不匹配时，通过可选XPC字段 `interfaceUnavailable` 标明兼容性问题；不把SMC连接失败或读回失败统称为未适配。

设置明确显示App上限未生效，提供系统电池设置入口。入口只打开系统设置，不修改上限、不读取确认系统限充，也不冒充自动切换到了系统管理。原有电池监测独立运行，缺失数据仍保持未知。

后台探测记录操作系统版本及固定键CHTE、CH0B、CH0C、CHIE、CH0I、bfF0、bfD0、bfE0的查询返回码；成功时记录类型、长度和可读性。查询失败不直接解释为键不存在；发现新版键也不授权写入。该诊断不遍历全部SMC，不输出序列号，不写控制键。

手动重新连接握手时，仅在没有硬件控制器、没有持有控制权且不处于恢复阶段时，重新运行失败的只读探测。恢复日志和现有安全更新流程保持不变。

新字段为可选字段，旧协议数据仍可解码；部署需要重新签名打包，并通过已有安全后台更新流程完成版本确认。此改动没有实现macOS 27的新充电控制协议。

## 无控制记录的安全迁移

管理员维护持有共享独占锁直到旧进程退出。旧接口缺失或布局不匹配时，只有root拥有、权限0700的真实恢复目录内，`lstat(active)`明确返回ENOENT，才能替代硬件automatic读回作为注册迁移条件。记录存在（含异常类型）、目录异常、权限错误、锁占用、控制值非automatic或读回失败均不能走此路径。退出后再次验证记录不存在，不删除恢复目录或记录，也不推断硬件已恢复。

显式命令`--retire-and-repair-battery-registration`要求其他App实例关闭，校验内嵌签名，通过管理员维护成功结果后才注销和重新注册；没有外部“已安全”参数可跳过检查。`--battery-install-verify`验证连接和hash，可同时报告限充不可用；连接验证成功不再被接口未适配错误混淆。

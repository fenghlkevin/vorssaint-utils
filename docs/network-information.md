# 网络信息

在 Vorssaint 菜单栏弹出面板顶部，点击地球图标「网络信息」标签，即可在面板内查看国内／国际 IPv4、归属地、运营商和 ASN，支持复制及刷新。不会创建额外的 macOS 菜单栏图标或独立详情窗口。

## 设置与入口

- 设置 → 网络信息：控制面板顶部标签是否显示，默认开启。
- 功能中心 → 工具 → 网络信息：独立开关，不依赖网络监控。
- 面板布局设置：可调整标签顺序。
- 命令栏搜索「网络信息」「公网 IP」「ASN」后，直接打开同一个面板标签。
- 仅点击刷新时查询，打开标签不会触发公网请求。

## 最近查询记录

设置 → 网络信息显示最近 10 次实际查询，每次查询的国内／国际结果归为一组，最新在前。记录时间、IP、归属地、运营商、ASN 和失败状态；使用缓存不重复记录。支持复制整组记录、单独复制 IP、删除一组及清空全部。

历史保存在本机，重启后保留，不随设置备份导出。清空时也会忽略已经在进行中的查询，避免记录立即重新出现。取消的查询不计入历史。

## 请求与数据

- 国内 IPv4 探测：`https://ipv4.ddnspod.com`，失败后自动切换至 `https://myip.ipip.net`。IPIP 文本响应只解析明确标注的 IP 字段，再执行严格 IPv4 校验；详情显示实际使用的节点。
- 国际 IPv4 探测：`https://api.ipify.org`（[ipify 文档](https://www.ipify.org/)）。
- 归属查询：`https://ipwho.is/{探测到的具体IPv4}`（[字段及额度说明](https://ipwhois.io/documentation)）。返回的 IP 必须与被查询 IP 一致，否则拒绝该响应。
- 采用 HTTPS 和系统默认代理／VPN 路由；不改代理设置、不忽略证书验证、不降级为 HTTP。代理规则和节点位置可能影响结果，切换代理后应手动刷新。
- 打开网络信息标签或设置页仅展示已有结果；首次使用请点击刷新。手动刷新会重新查询，失败后可点击刷新重试。
- 两路并发、同一路请求合并。IP 探测成功后立即显示；归属服务失败时保留新 IP，不挪用旧 IP 的归属数据。
- 系统网络路径变化时取消旧请求并使缓存过期，等待手动刷新；没有定时公网轮询。
- 查询历史仅在本机保存最近 10 次，可在设置中删除。没有 Cookie 或磁盘响应缓存。接口会接收到请求；探测到的 IP 会发往归属服务。第三方服务的额度、数据准确性和可用性依赖其当前政策。
- 第一版仅 IPv4，不支持 IPv6、自动代理识别或精确地理定位。数据缺失显示「暂无数据」，不猜测。

## 验证

`bash Tools/test-network-info.sh`：离线验证 IPv4 校验、响应字段缺失／IP 不一致、缓存和退避、双路探测、429、取消请求、网络切换、命令栏开关与排序。已加入 `build.sh --test`。

`bash Tools/test-network-info.sh --live`：显式发起实际探测和归属查询，仅打印成功状态及错误码，不打印公网 IP。

2026-09-13：原国内节点 `4.ipw.cn` 在当前网络中发生 TLS 安全连接错误（-1200），已移除该依赖。两个新国内接口的 HTTPS 可用性已验证；未绕过 TLS 验证或降级 HTTP。修复后使用 URLSession 实测国内（ipv4.ddnspod.com）及国际（api.ipify.org）均成功获取 IPv4、归属地、运营商和 ASN。

## 内网 IP

网络信息标签顶部显示本机已启用网卡的 IPv4 地址及接口名，支持逐个复制。仅点击刷新时重新读取，不受出口查询缓存或失败影响。排除回环与 Apple 点对点接口，VPN 隧道独立展示；虚拟机桥接接口（如 bridge100、bridge101）也单独展示；多网卡分别展示。地址只从本机读取，不发送给归属查询服务，并随新查询保存在本机历史中。

## 设置页概览与隧道地址

设置页仅点击刷新时查询当前网络，以两列卡片显示内网、VPN/隧道和国内、国际出口。活动 tun、utun、tap、ipsec 及点对点接口的 IPv4 单独展示，不据接口名推断 VPN 应用。历史以紧凑行显示，展开查看归属详情；新查询保存开始时的本机接口快照，旧记录显示“未记录”。读取失败不会保存为“无地址”。

打开菜单栏网络信息或设置页不会自动查询；本机地址、VPN 和出口均由“刷新”按钮更新。网络变化只使出口结果失效并取消正在进行的请求，不触发新查询。

应用重启时从最近一条本机历史恢复整组查询快照（内网、VPN、出口和详情），显示保存时间与提示。恢复过程不联网、不读取网卡、不新增历史，需手动刷新确认当前地址。清空历史后重启不再恢复。

结果卡片以“上次查询结果”显示查询时间；恢复历史不显示过期警告。仅收到系统网络变化通知时显示“网络已变化，可手动刷新”，成功查询会清除此提示。刷新失败仍保留旧结果并显示实际错误。

# 电源与显示器

设置 → 电源与显示器：分别编辑使用电池和接通电源时的策略。

- 空闲模式：跟随系统、电脑运行但允许熄屏、屏幕常亮。
- 外接显示器可以覆盖空闲模式；不再使用“外屏或电源”两个独立触发器。
- 合盖使用外屏单独配置，首次使用需授权。仅检测到活动的非虚拟外屏时启用；拔掉外屏、低电量或手动休眠时解除。
- 当前合盖实现仍使用系统级 disablesleep，因此开启合盖规则期间也不会自动休眠。菜单栏明确显示这一点；需要主动休眠时使用本应用的“立即休眠”。不声称 Apple 菜单的睡眠能绕过此系统限制。
- 自动关闭内屏默认关闭，支持双屏、合盖外屏和无外屏使用。需要开启显示器控制，复用现有最后一块可用屏幕保护和断线恢复。
- 菜单栏模式是临时覆盖；计时结束恢复默认策略。锁屏释放显示常亮或恢复系统行为，取决于锁屏设置；锁屏不再移动鼠标。
- “立即休眠”先暂停本应用规则，等待合盖写入完成，确认电池后台已关闭防休眠断言，再读取系统电源状态并发出 sleepnow。失败有可见提示；唤醒恢复默认策略。
- 旧电源/外屏自动化迁移到两个独立配置；充电上限等仍由电池管理负责。配置纳入设置备份。

自动化测试不触发真实锁屏、休眠、显示器开关或充电硬件写入。实机验收需覆盖：电池合盖外屏、接电合盖外屏、拔掉外屏恢复内屏、锁屏后解锁、手动休眠后唤醒、拒绝合盖授权、低电量。不同机型、扩展坞和 macOS 对合盖外屏的支持需要实机确认。

# 翻译

在「功能 → 工具」启用「翻译」，然后打开侧栏独立的「翻译」设置页。页面提供服务、来源／目标语言、划词和截图快捷键、权限入口与隐私说明；服务和语言选择自动保存，翻译窗口与设置同步。命令栏也可搜索翻译。窗口快捷键 Ctrl–Option–Shift–T 默认启用，无需辅助功能权限；可在设置里修改。划词和截图快捷键默认关闭，可在设置里启用划词（Ctrl–Option–Shift–D）和截图（Ctrl–Option–Shift–S）。

截图翻译使用专用直接选区模式：拖动框选、松开鼠标即进行本地 Vision OCR，不进入截图标注编辑器，也无需确认；Esc 取消。复用底层屏幕捕获和多屏选区，不影响普通截图的编辑确认流程。划词使用辅助功能权限。截图识别或划词成功后，自动使用上次选择的服务翻译；使用 AI / Codex 时会向相应云端发送取得的文本并可能消耗费用或额度。失败、空文本或超长文本不会发起请求。手动输入、粘贴和修改原文仍需点击「翻译」或 Shift–Enter / Command–Enter；普通 Enter 仍换行。

翻译窗口内 Shift–↑ / Shift–↓ 循环切换 Apple → AI → Codex 服务（向上反向），并自动保存，关闭窗口或重启后沿用上次选择。快捷键会占用窗口内原有的 Shift–方向键选行操作，但输入法组词时不拦截。切换会取消旧请求，不自动重发；AI / Codex 具体模型继续沿用设置页保存的配置。

Apple 源语言选择「自动检测」时交由系统识别；短词、混合语言等无法明确识别时系统可能要求选择语言。自动检测不等同于自动改变目标语言。

已保存的 API Key 以固定掩码显示，不回填真实密钥；输入新 Key 即替换，留空沿用当前接口的原 Key。更换接口后不显示旧接口的掩码，也不会沿用旧 Key。

## 翻译服务

### AI / DeepSeek API

在独立「翻译」设置页的「AI · API」区域填写完整 HTTPS Chat Completions URL、模型 ID 和 API Key，点击保存，再将翻译服务切换为「AI · API」。默认地址为 `https://api.deepseek.com/chat/completions`，默认模型 `deepseek-v4-flash`；模型可自行修改。兼容接口需支持 `messages`、`stream: false`、`max_tokens` 和 `choices[0].message.content`，不保证所有厂商兼容。

原文在手动提交翻译或截图／划词成功后发送到配置的接口，可能产生费用。Key 与接口配置绑定保存在系统钥匙串，不随设置导出；Key 留空只在接口不变时保留原值，修改接口须重新输入 Key。不跟随重定向，不记录密钥或服务端错误原文，不自动重试。请求超时 60 秒、整体 90 秒、响应上限 2 MB；拒绝将截断结果当作完整译文。无真实 Key 时只能进行本地请求和响应协议测试，不能宣称账号调用成功。

### Codex CLI

在翻译设置或窗口选择「Codex · CLI」。使用本机已安装并通过 `codex login` 登录的 CLI，无需在 Vorssaint 填写 Key。CLI 路径留空会检测常见 npm / Homebrew 路径，也可指定绝对路径；npm 入口会解析到原生二进制，不启动 Node 包装器。

设置提供模型、速度、推理强度三个下拉框。模型和能力由本机 `codex debug models` 目录提供，可手动刷新；目录不保证账户权限，实际可用性以服务端为准。选择具体模型后，才能选择其支持的强度和速度；快速模式仅对目录声明支持 priority/fast 的模型提供，并可能增加额度消耗。切换模型将强度和速度重置为默认。旧版手填模型保留为当前选项，不自动迁移到其他模型。目录读取失败不猜测能力，不放宽调用权限。

设置自动保存。推理强度传入 `model_reasoning_effort`，快速模式传入 `service_tier="fast"`；默认选项不传覆盖值。翻译开始前重新校验非默认参数与模型能力，目录查询限时 25 秒。翻译调用不会加载用户的 config.toml、MCP、插件或项目指令，因而不会继承其中的自定义接口和模型配置；模型目录命令使用 CLI 自己的配置与认证加载逻辑。

每次使用独立临时目录、只读沙盒和临时会话；禁用 shell、统一终端、浏览器、应用连接、插件、hooks、多智能体、图片与网络搜索功能。原文通过 stdin 发送，不放在进程参数中；仅接受完成的纯文本消息，工具活动和失败会话不作为译文展示。可取消，120 秒超时，输出限 2 MB。设置变更、输入变更及关闭窗口都会取消本次调用。错误不会展示 CLI 原始日志或凭据。

这不是本地离线模型：原文会发往 Codex 云端，消耗登录账户额度，受其服务与数据政策约束。Vorssaint 不读取、复制或导出 Codex 凭据；CLI 自行使用默认登录存储。不支持自定义 CODEX_HOME 或 shell 包装脚本。CLI 版本参数不兼容、登录失效、网络或额度问题会报错，不降级到更宽松的权限。ChatGPT 桌面应用自动化未实现。

- Apple：macOS 15+ 本地翻译；首次可能下载语言模型。
Google 翻译已移除；以前选择 Google 的配置会在启动时自动回退为 Apple。

Apple 翻译内容在本机处理；首次使用可能需要下载 Apple 语言模型。窗口、划词、截图和复制功能保留。

## Bob 插件已屏蔽

当前不展示导入、选择和配置入口，不读取已安装插件，不允许安装或执行插件，命令行 worker 入口也已禁用。已有插件文件和钥匙串配置保留，未删除。兼容层源码和隔离单元测试暂时保留，供后续决定是否恢复；不能将其单元测试通过解释为应用支持插件。

## 验证

使用 `swift build` 验证完整界面与服务编译。插件兼容层测试仅保留为源码回归测试，不代表插件功能开放。

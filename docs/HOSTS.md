# Hosts 管理

在“功能中心 → 工具”安装 **Hosts 管理**，然后打开设置中的 Hosts 工作台。也可以从菜单栏面板的 Hosts 管理入口打开。

## 配置与切换

1. 点击 `+` 创建本地配置，填写名称与 Hosts 内容。
2. 每行写 `IP 地址 域名 [其他域名]`；支持 IPv4、IPv6、多个域名和 `#` 注释。国际域名使用 Punycode。
3. 保存配置，勾选需要组合启用的配置，检查组合预览与错误提示。
4. 首次应用时点击“授权 / 更新助手”，按 macOS 要求批准网络助手，然后刷新授权状态。
5. 点击“应用组合”。菜单栏中的配置开关会立即尝试应用整个组合；失败时保留选择，并显示“配置待应用”和失败原因。

保存、删除和工作台勾选仅修改本地草稿；需要“应用组合”才会同步系统文件。相同域名在 IPv4 与 IPv6 中可以各有一条记录，同一地址族中不同地址的映射会阻止应用。系统原有记录与所选配置冲突时也会阻止应用。

## 系统内容与恢复

- “系统 Hosts”显示 `/etc/hosts` 的只读快照；外部编辑后点击“刷新”。
- 仅维护 `BEGIN VORSSAINT HOSTS` / `END VORSSAINT HOSTS` 标记区块，保留其他内容。
- “停用全部”移除管理区块并停用本地配置，保留配置库。尚未应用的组合也可以直接取消，不需要网络助手；原系统及其他工具的记录保持不变。
- 助手连接在应用前验证签名与版本。系统仍在运行旧助手时，仅在系统代理与 TUN 均未使用它的情况下更新注册；若有正在使用的会话，会提示先停止网络代理。
- 应用前自动保存完整原文件及管理区块，保留最近 30 份；恢复只恢复管理区块，保留系统当前的其他记录。
- 恢复后，原配置保留并停用，恢复内容作为一份新的本地配置启用。可以复制备份中的完整原文件供手动检查。
- 数据保存在应用私有 Application Support 容器中的 `Hosts/library.json`，开发版和正式版独立。
- 签名网络助手另外在 `/private/var/db/<网络助手标识>-hosts/previous.hosts` 保存最近一次实际写入前的恢复文件，目录与文件仅 root 可访问。

网络助手使用固定的系统 Hosts 路径，不接受任意路径或命令。写入前检查文件归属、权限、类型、内容快照与管理标记，并采用同目录临时文件原子替换。写入成功后刷新系统 DNS 缓存；刷新失败会单独提示，不将已完成的写入报告为失败。

## 生效范围

退出 Vorssaint、关闭工作台或卸载 Hosts 模块不会移除已应用的映射。需要恢复时先点击“停用全部”。模块没有后台定时刷新或远程订阅。

自定义 DNS、代理远端解析或 TUN 可能绕过 macOS 系统 Hosts；Hosts 管理不修改 Mihomo 的 DNS 或 hosts 配置。应用自身缓存也可能需要重启应用后才更新。

## 验证

运行 `bash Tools/test-hosts.sh` 检查解析、冲突、原文件保留、备份、外部修改拒绝和安全写入。测试只使用临时目录，不修改本机 `/etc/hosts`。

# 窗口贴边排列

窗口布局的主要操作是直接拖动窗口标题栏，无需按住修饰键。开启菜单栏面板或设置中的「将窗口贴靠到屏幕边缘」，并授予辅助功能权限。如果 macOS 窗口平铺已开启，界面会显示冲突及系统设置入口；关闭系统平铺后切回应用即可启用，不必重新打开面板。

## 拖动规则

| 位置 | 布局 |
| --- | --- |
| 横屏左右边缘 | 左右半屏 |
| 四角 | 对应四分之一屏 |
| 顶部中央 | 当前显示器内最大化（不进入系统全屏空间） |
| 横屏底边，从左到右滑动 | 左 1/3、左 2/3、中间 1/3、右 2/3、右 1/3 |
| 竖屏两侧，从上到下滑动 | 上 1/3、上 2/3、中间 1/3、下 2/3、下 1/3 |
| 竖屏底部中央 | 下半屏 |

四角优先于相邻的分区。预览使用最终布局的同一矩形和间距设置。分区切换保留小幅防抖；移开屏幕边缘立即取消预览，Esc 取消本次吸附。显示器共享边界保持开放，便于跨屏拖动。

将 Vorssaint 排列过的窗口拖离时，恢复排列前的大小并保留标题栏上的抓取比例。恢复大小不会超过目标显示器的可用区域。用户手动改变尺寸后，不再套用旧的恢复尺寸。恢复记录仅在当前进程运行期间有效。

## 操作入口

常用布局提供示意图、名称和已启用的快捷键。六分屏、系统全屏、带边距最大化及按修饰键自由拖动位于「更多布局与操作」。设置中将贴边排列和修饰键自由拖动分开，避免混淆。

## 悬浮分屏岛

开启“悬浮分屏岛与贴边吸附”后，原生标题栏拖动确认开始时，在指针所在屏幕上方显示分屏岛。靠近后展开七组布局：最大化、左右二分、上下二分、三分、左大右小、左小右大、四分。拖入具体格子显示目标预览，松手应用；离开格子清除选择，离开岛收起，Esc 取消本次吸附。原有边缘吸附仍可用。

实现使用不激活、不接收鼠标事件的 NSPanel，并共享绘制与命中测试几何；不需要录屏权限。位置相对屏幕可用区域计算，避开菜单栏与刘海，并给现有顶部灵动岛保留间距。分屏岛空白区域不会触发顶部最大化，跨屏时重置展开状态；停止监听、结束拖动和取消时隐藏。

布局命中测试覆盖负坐标副屏、竖屏、窄屏、所有 16 个布局格子、展开与退出边界。实际窗口尺寸仍受目标应用最小尺寸约束。

## 分屏过渡动画

分屏岛展开、收起使用约 0.20 秒缓出动画，隐藏淡出约 0.14 秒；预览框在布局间移动与缩放约 0.16 秒。松手落位通过约 0.20 秒的三次缓出插值更新目标窗口的位置和大小，最后复用原有落位校验及尺寸限制处理。新的鼠标按下、其他落位操作、停止监听或服务暂停会取消进行中的窗口动画并恢复辅助模式。系统“减少动态效果”开启时跳过新增移动与缩放动画。

### 展开卡顿修复

分屏岛使用固定的展开尺寸透明窗口，不再在展开期间逐帧改变 NSPanel 尺寸。紧凑态和展开态的内容分别绘制到图层，由 Core Animation 完成缩放与交叉淡入；快速反向切换从当前呈现状态衔接。删除 `alphaValue < 1` 引发重复启动动画的条件，动画仅在展开状态、屏幕或显隐状态变化时触发。布局按屏幕缓存；只有选中的格子改变才重绘高亮，连续拖动事件不再重复重画全部内容。

### 展开原点修复

展开动画改为独立 CALayer 子图层，避免 AppKit 重新布局视图时覆盖 backing layer 的锚点与位置。锚点固定为展开面板的顶部中心，缩小态的宽高精确对应紧凑小框；内容离屏绘制并缓存到图层。使用真实 CALayer 对 3 种宽度、各 21 个过渡帧检查，63 帧均保持水平中心与顶部固定，起点尺寸与小框一致。

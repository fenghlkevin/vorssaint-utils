# 电池动态日志

设置 → 电池管理 → 电池诊断与事件，可展开最近电池采样。诊断报告保持静态快照，点击刷新重新读取本地日志，不发起后台修复。复制全部日志包含连接事件及电池采样，按时间倒序合并。

电池面板模型存活期间每30秒（允许5秒调度容差）、打开菜单、系统唤醒时采样。采样在后台队列进行，不需管理员授权，也不改变充电策略。休眠、退出和调度延迟期间不能保证采样；超过90秒的间隔明确标为未知，不能根据两个端点重建期间供电。

每条采样记录：电量及变化、外接电源/系统充电标志、Voltage、Amperage和InstantAmperage、V×I电池功率、原始PSTR/PDTR功率、适配器额定功率、原始容量、显示与原始温度及来源、健康/循环/剩余时间、应用模式、有效上限、后台就绪状态及响应年龄。缺失值标为未知；负功率绝对值小于0.5W也保留并标为微小放电读数，不宣称持续放电已确认。

PSTR和PDTR为不同传感器读数，非同步测量。菜单电脑功率可能经过推算或回退，不用于代替日志里的PSTR原始读数。电池功率继续沿用现有Amperage优先的算法，双电流字段同时保留用于诊断读数冲突。一次零电流不能证明此前没有放电。

控制日志区分用户请求、准备同步的有效配置和带请求ID的后台响应；响应记录command、override、active、温控状态和错误。配置只在变化时记录，不含自动化地点或规则名称。不记录电池/适配器序列号。

连接事件最多1000条，采样独立保留3000条（常规30秒采样约25小时，频繁打开菜单会缩短覆盖时间），存入本机UserDefaults，重启后保留。清空全部日志同时清空两类应用内历史并重置比较基线，不能撤销；后续采样继续。不会删除电量图表、后台安全恢复记录或macOS统一日志。

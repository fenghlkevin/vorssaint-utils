# 实时字幕（第一版）

入口：菜单栏图标展开面板 → 顶部“实时字幕”独立 Tab（字幕气泡图标）→ 打开字幕窗口。已移除底部快捷按钮。Tab 随功能开启显示，支持现有面板排序与隐藏设置；旧布局会自动追加新 Tab。更多菜单可独立启用/关闭实时字幕，也可停止并关闭字幕窗口。设置 → 功能中有独立“实时字幕”条目；翻译设置中也有对应开关。默认关闭，与普通翻译的功能开关互不影响。

macOS 26+ / Apple Silicon，需已安装英语本地识别模型及系统采集权限。

- 支持整个系统声音、英语／日语／葡萄牙语→简体中文。葡萄牙语可选巴西或葡萄牙口音。记住上次源语言，需停止后切换；缺少所选本地识别模型会提示，不自动下载。无麦克风、无音频保存。
- Apple：已有本地翻译语言包，支持提前预译及定稿修正。
- AI API：复用已有命名配置及钥匙串中的 Key；仅定稿后调用。
- Codex CLI：复用现有路径、模型、速度、强度和登录配置；仅定稿后调用，可能明显慢于 Apple。
- 云端服务开始前需明确勾选发送字幕许可；只发送英文文本，不发送音频。可能产生费用/额度消耗。
- 服务切换需先停止。字幕服务选择独立记忆，不影响普通翻译窗口。
- 无边框深色半透明悬浮字幕条，默认显示最近 3 条（可配置 1～5 条）；每条可显示译文和原文，长句换行。历史最多 80 段仅驻内存。
- 中文大字、原文小字；字号 18～36，背景不透明度 25%～95%，设置自动保存。工具栏悬停显示，停止状态保持可见。
- 字幕宽度可设为所在屏幕可用宽度的 40%～100%，默认 70%，至少 600 点（极小屏幕不超出可用宽度）。调整时尽量保持中心位置，跨屏后按新屏幕比例重新适配。
- 工具栏橡皮擦按钮“清屏”：清除内存字幕、临时原文及待处理译文，取消当前翻译，不停止声音采集。已清除语音段的迟到结果不会重新出现；正在说的一段可能丢弃，从下一段继续。停止状态同样可清屏。
- 可置顶、拖动背景、鼠标穿透；穿透后从菜单 Tab 再次打开窗口可恢复操作。设置弹层内折叠诊断信息。
- 持续运行，不再 5 分钟自动停止；暂停会取消未完成任务，再次开始新会话。关闭字幕窗口或关闭实时字幕功能会停止采集与待处理请求，不受普通翻译功能开关影响。
- 云端最多保留 2 条待翻译项，Apple 最多 8 条；积压时跳过旧句。超时与错误显示在对应行，不自动切换服务。

日语按句号、问号或最多 48 字分段，不依赖英文空格。三种翻译后端均传入所选源语言。各语言识别与翻译语言包分别检查。

本版尚无指定应用音源、自动检测语种、SRT/VTT 导出、视频时间轴同步。这些适合后续字幕工具迭代，不将识别时间冒充视频时间码。

验证：完整开发版编译和签名；离线分段、云端许可、仅定稿发送、队列策略测试。不自动向真实 AI 服务发送测试字幕，AI/Codex 实时链路仍需用户选定服务后实测。

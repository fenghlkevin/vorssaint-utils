# 命令栏开发者工具

在命令栏搜索 `json`，点击搜索结果中的 **“内部 JSON 工具”**（或选中后回车），会弹出一个独立的工具编辑器窗口。粘贴文本、运行和复制结果都在这个窗口中完成。其他文本工具同样作为内部工具启动，也可通过中文名称搜索。**Tab 保持命令栏原有的补全功能，不负责打开工具。** 内部小应用由各自的开关独立控制；关闭“操作”来源不会影响它们的搜索和启动。

| 命令 | 功能 | 示例 |
| --- | --- | --- |
| `json` | JSON 格式化、按键名排序 | `json {"b":2,"a":1}` |
| `json min` | JSON 压缩 | `json min { "a": 1 }` |
| `base64 encode` | UTF-8 文本转标准 Base64 | `base64 encode hello` |
| `base64 decode` | 标准 Base64 转 UTF-8 文本 | `base64 decode aGVsbG8=` |
| `url encode` | URL 参数值百分号编码 | `url encode a+b c` |
| `url decode` | 百分号编码转 UTF-8 文本 | `url decode a%2Bb%20c` |
| `timestamp` | 秒/毫秒/ISO 8601 转换 | `timestamp 1700000000000` |
| `uuid` | 生成随机 UUID | `uuid` |
| `diff` | 两份文本逐行比较 | `diff`，随后在左右输入框粘贴文本 |
| `port` / `端口` | 查询本地端口占用 | `port 8080` |

## 开关与自定义快捷输入

打开 **设置 → 命令栏 → 内部小应用**：

- JSON 格式化、JSON 压缩、Base64 编码/解码、URL 编码/解码、时间戳、UUID、文本对比和端口查询都有独立开关。关闭后该工具从搜索结果消失，也不能通过已有入口运行。重新开启会保留原有触发词。
- 每行的 **快捷输入** 可以自己修改。例如把 JSON 格式化的 `json` 改为 `jsonx`，点击 **保存**，之后输入 `jsonx` 或 `jsonx {"a":1}` 即可找到并打开 JSON 工具。
- 快捷输入不区分大小写，以文字开头，支持文字、数字、空格、下划线和短横线，最长 32 个字符。工具之间不能使用相同触发词，保存前会提示冲突；也可以恢复单个工具的默认触发词。
- 上表列出的是默认命令。更改后，参数解析使用新的触发词；仍可按工具中文名称或 JSON、Base64 等名称搜索。
- 端口查询也可以改名，例如改成 `ports` 后使用 `ports 8080`；改名后不再使用原来的 `port` / `端口` 快捷输入。
- 关闭正在编辑的工具时，已有文本保留，但“运行”会停用；可重新启用后继续。编辑器的工具选择列表只提供已启用的工具。
- 开关和快捷输入会持久保存，并包含在 app 的设置导出、导入中。

## 文本工具

- 搜索 `json` → 点击 **内部 JSON 工具** → 在弹出的编辑器输入或粘贴内容 → **⇧↩ 运行** → **复制结果**。
- 命令后可以直接带输入；只搜索工具名称时打开空白编辑器，可点击“粘贴”或使用 ⌘V 输入剪贴板内容。时间戳留空表示当前时间，UUID 不需要输入。
- 编辑器是可以拖动、缩放和最小化的独立窗口。关闭或重新打开命令栏不会影响当前编辑；再次启动同一工具会将已有窗口带到前台。点击关闭按钮或按 `⌘W` 关闭编辑器时清除内容。
- 输入框支持多行和普通复制粘贴。按 `⇧↩` 或点击“运行”处理，点击“复制结果”复制完整输出；普通回车用于换行。
- 工具可以在编辑区顶部切换。文本仅在本机处理，不写入工具历史；复制结果会进入系统剪贴板，也会遵循用户已有的剪贴板历史设置。
- URL 工具编码的是参数值，空格用 `%20` 表示；解码不会把 `+` 改成空格。
- 时间戳输出 Unix 秒、毫秒、UTC 和本地时间。数字绝对值达到 `100000000000` 时自动按毫秒解释；可用 `s:` 或 `ms:` 显式指定单位，例如 `timestamp ms:1000`。日期输入使用带时区的 ISO 8601，例如 `2023-11-14T22:13:20Z`。
- 文本对比中，`-` 表示删除，`+` 表示新增，两个空格开头表示未改变的行；保留空白和末尾换行差异。
- JSON 格式化和压缩支持最多 50 MB UTF-8 输入，可点击“打开文件…”导入并自动运行。超过 1 MB 的原文默认收起，可点“编辑原文”修改。
- JSON 结果以树形展示，点击对象/数组旁的箭头展开或收起；“展开选中”展开一层，“全部收起”折叠树。搜索键名和值（不区分大小写），用 ↑ / ↓ 循环定位匹配，自动展开父级。长值在单元格中缩略显示，但搜索和复制结果包含完整内容。
- 其他工具每份输入最多 256 KB；对比每份最多 2000 行，两份行数乘积最多 200 万。其他工具结果预览最多 24000 字符，复制不截断。

## 端口占用与强制结束

输入 `port 8080` 后自动查询，无需先回车。结果包含进程名、PID、本地地址、TCP/UDP 类型和可执行文件路径；可复制完整诊断信息或手动刷新。

选择“强制结束”进入命令栏原有的确认界面，再次回车发送 `SIGKILL`；`Esc` 取消。执行前重新核对进程启动时间、路径及端口占用，操作后重新查询端口。同一端口有多个进程时，逐个选择要结束的进程。

查询范围是当前用户可见的 **TCP 监听端口和 UDP 本地绑定**，不把远端连接端口当作本地占用。无结果不代表其他用户或系统进程一定未占用。关键系统进程、Vorssaint 自身、身份无法核实的进程不会提供强制结束按钮；没有权限时显示具体错误，不自动提权。被其他程序自动重启的服务可能在刷新后出现新 PID。

## 验证

```sh
bash Tools/test-command-bar.sh
bash Tools/test-command-bar.sh --integration
```

集成测试只创建本机回环地址上的临时 TCP/UDP 监听进程，核对过期身份拒绝逻辑后，强制结束这个测试子进程并验证端口释放。

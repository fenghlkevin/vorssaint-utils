# Vorssaint

面向 macOS 的一体化菜单栏工具，把常用系统能力集中在一个入口中。免费、开源，核心处理优先在本机完成。

Vorssaint 提供声音控制、系统监控、窗口管理、剪贴板、文件处理、翻译、截图录屏和电源管理等功能，并支持按需启用、卸载、隐藏和排序功能模块。

## 主要功能

### 翻译

- 支持划词、手动输入、剪贴板文本和截图 OCR 翻译。
- 支持 Apple 本地翻译（macOS 15+）、AI / DeepSeek API，以及本机 Codex CLI。
- 可分别配置服务、快捷键和输出方式；Google 翻译已移除，Bob 插件继续屏蔽。
- 本地翻译和云端翻译分开管理；云端服务可能消耗 API 额度或产生费用。

详见[翻译指南](docs/TRANSLATION.md)。

### 输入法自动切换

- 可按应用或浏览器网站设置输入法规则，网站规则优先。
- 支持跟随上次使用的输入法，以及强制英文标点。

### 离开自动锁定

- 通过选定蓝牙设备的距离或连接状态判断是否离开 Mac。
- 离开后倒计时锁定，设备返回时可请求唤醒显示器。
- 支持多设备策略、误锁保护、通知、节能模式和诊断日志。

### 菜单栏图标折叠

- 通过可拖动分隔按钮收起其左侧的菜单栏图标。
- Vorssaint 图标和分隔按钮始终保留，方便恢复。
- 支持展开后延时自动折叠。

### 重写后的屏幕捕捉

- 支持区域、窗口、全屏、滚动截图和录屏。
- 截图后可直接原位编辑：矩形、椭圆、箭头、画笔、荧光笔、文字、数字标记、马赛克、放大镜和水印。
- 支持调整截图范围、移动和再次编辑标注，可复制到剪贴板或保存到“下载”目录。
- 滚动截图支持纵向和横向拼接，并提供实时合并预览；Esc 取消，回车或对号完成。
- 支持 OCR、二维码识别、自动缩放、GIF/视频导出和音轨编辑。

滚动截图依赖相邻画面的可识别重叠内容。动态画面、重复文本、大面积空白或滚动过快可能影响拼接结果。

### 其他能力

- 命令栏开发者工具：JSON、Base64、URL 编解码、时间戳、UUID、文本对比，以及端口占用查询和进程强制结束。详见[使用指南](docs/COMMAND-BAR-DEVELOPER.md)。

- 应用音量混合器、按应用选择输出设备、麦克风静音和音乐应用启动拦截。
- CPU、GPU、内存、磁盘、温度、电池、风扇和网络监控。
- 应用切换器、窗口布局、Dock 窗口预览、命令栏、快捷面板和径向菜单。
- 剪贴板历史、纯文本粘贴、文件暂存架、Finder 增强、链接清理和 DMG 安装。
- 屏幕取色、摄像头预览、便笺、应用更新、清理器、卸载器和清洁模式。
- 保持唤醒、显示器亮度控制、额外亮度，以及睡眠时暂时关闭蓝牙。

## 按需启用

“功能中心”可以单独安装或卸载完整功能模块。未启用的模块不会加载，也不会占用对应的 CPU、内存或电量；已有设置会保留，重新安装即可恢复。

首次启动可以选择基础、窗口或省电静音预设，也可以逐项选择功能。面板支持排序和隐藏，设置支持导出与导入。

## 安装

```sh
brew install --cask vorssaint
```

也可以从 [Releases](https://github.com/vorssaintapp/vorssaint-utils/releases) 下载磁盘映像，并将 Vorssaint 拖入“应用程序”。

卸载：

```sh
brew uninstall --cask vorssaint
```

## 隐私与权限

Vorssaint 默认在本机处理数据，不要求账号，不内置分析或跟踪。更新检查、测速、Homebrew、云端翻译和临时截图/录屏分享等明确功能可能访问网络，详见[隐私说明](docs/PRIVACY.md)。

部分功能需要“辅助功能”“屏幕与系统音频录制”“输入监控”或蓝牙相关权限。权限均为可选，完整说明见[权限指南](docs/PERMISSIONS.md)。

截图诊断日志默认关闭，日志可能包含实际屏幕内容，仅保存在本机：

```text
~/Library/Logs/Vorssaint/ScreenshotDiagnostics/
```

## 从源码构建

要求：Apple 芯片 Mac、macOS 14 Sonoma 或更高版本、Xcode Command Line Tools。

```sh
./build.sh --dev --install
./build.sh --test
```

开发版可以与正式版共存。如需沿用已有开发签名身份：

```sh
VORSSAINT_DEV_SIGNING_IDENTITY='你的开发签名身份' ./build.sh --dev --install
```
